# 쇼츠메이커 CLOUD V3.4 업로드

압축을 푼 뒤 이 폴더 안의 항목을 전부 GitHub 저장소 최상단에 올리세요.

1. GitHub 저장소 → 파일 추가 → 파일 업로드
2. 이 폴더 내부 전체 선택 후 끌어놓기
3. 변경사항 커밋
4. Streamlit 앱 → Manage app → Reboot
5. 화면 상단에 `쇼츠메이커 CLOUD V3.4` 표시 확인

## V3.4 핵심 변경

- 30·45·60초 선택값에 최종 MP4 길이 고정
- 짧은 대본 자동 보강 및 장면 수 확대
- 동일 인물·주제의 Wikimedia Commons/Wikidata 권리확인 사진 자동 검색
- Public Domain, CC0, CC BY, KOGL Type 1 기본 허용
- CC BY-SA는 사용자가 별도로 켠 경우만 포함
- 사진 저작자·라이선스·URL 자동 기록
- 윤영×남성 하이브리드 음성 추가
- 여성 쇼츠 시그니처 음성 추가
- 직접 보유한 사진 업로드 기능 추가

네이버 기사 안의 사진은 사용 권한이 자동 확인되지 않으므로 직접 복사하지 않습니다. 같은 인물·주제의 공개 라이선스 사진을 찾아 사용합니다.
