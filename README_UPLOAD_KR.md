# 쇼츠메이커 CLOUD V3.5 업로드 방법

압축을 푼 뒤 이 폴더 안의 항목을 GitHub 저장소 최상단에 전부 올리세요.

1. GitHub 저장소에서 `파일 추가 → 파일 업로드`
2. 압축을 푼 폴더 내부를 `Ctrl+A`로 전체 선택
3. 파일과 폴더를 GitHub 업로드 화면으로 끌어놓기
4. `변경사항 커밋`
5. Streamlit 앱에서 `Manage app → Reboot app`
6. 화면 상단에 `쇼츠메이커 CLOUD V3.5`가 표시되는지 확인

## 적용 확인

- 나레이션 목록에 `여성 참고음성 A`, `여성 참고음성 B`가 보입니다.
- 두 여성 음성 설명에 `남성 레이어 없음`이 표시됩니다.
- `선택한 AI 목소리 7초 미리듣기` 버튼이 보입니다.
- 영상 템플릿 기본값이 `엔터 밝은 인물형`입니다.
- 기사 분석 후 `기사 주인공 실제 사진 · 라이선스 확인 결과` 영역이 나타납니다.

## 사진 사용 원칙

- 기사 페이지에 공개 라이선스가 명확히 표시된 경우만 기사 이미지를 후보로 사용합니다.
- 일반 네이버·언론사 사진은 출처만 적는다고 사용할 수 있는 것이 아니므로 자동 복사하지 않습니다.
- Wikidata/Wikimedia Commons에서 상업적 재사용 조건이 확인되는 실제 인물 사진을 우선 검색합니다.
- 검색 결과가 없으면 직접 보유하거나 사용 허가를 받은 사진을 업로드해야 합니다.
