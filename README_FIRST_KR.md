# 쇼츠메이커 CLOUD V3.0

집 노트북, 회사 PC, 휴대폰에서 **같은 Streamlit 웹주소**로 접속해 쇼츠를 만드는 클라우드 버전입니다.

## 핵심 구조

- 개인 노트북을 서버로 사용하지 않습니다.
- 집 노트북이나 회사 PC가 꺼져 있어도 웹주소는 열립니다.
- Gemini/Pexels API 키 입력이 필요 없습니다.
- 기사 사진과 방송 화면을 자동으로 사용하지 않습니다.
- 기사 제목·핵심어·수치만 구조화해 새 해설 대본을 만듭니다.
- 장면은 프로그램이 직접 생성한 에디토리얼 그래픽을 사용합니다.
- 내 목소리 녹음 보정과 AI 성우를 모두 지원합니다.
- 콘텐츠 유형에 따라 내장 오리지널 BGM을 자동 선택합니다.

## 기존 GitHub 저장소에 반영

1. 이 폴더 안의 파일을 기존 `shorts-maker-web` 저장소에 업로드합니다.
2. 기존 파일 교체 표시가 나오면 그대로 커밋합니다.
3. Streamlit Community Cloud가 같은 앱 주소를 자동 재배포합니다.
4. 집·회사·휴대폰에서 기존 앱 주소를 열어 사용합니다.

업로드 대상:

- `streamlit_app.py`
- `shorts_engine.py`
- `requirements.txt`
- `packages.txt`
- `.streamlit/config.toml`
- `assets/`

## 휴대폰 바로가기

- Android Chrome: `⋮` → `홈 화면에 추가`
- iPhone Safari: `공유` → `홈 화면에 추가`
- Windows Chrome/Edge: 주소창의 설치 또는 바로가기 아이콘

## 기기 간 대본 이동

새 영상은 어느 기기에서든 바로 만들 수 있습니다. 작성 중인 대본을 다른 기기로 옮길 때는 앱의 `다른 기기용 프로젝트 저장` 버튼으로 JSON을 내려받고, 다른 기기에서 `프로젝트 불러오기`를 사용합니다.

## 중요한 제한

- 무료 클라우드 서버의 CPU·메모리 한도 때문에 1080×1920은 오래 걸릴 수 있습니다. 기본 720×1280을 권장합니다.
- 영상 제작 중 브라우저 탭을 닫으면 해당 작업 세션이 끊길 수 있으므로 완성될 때까지 탭을 유지하세요.
- AI 성우는 별도 키 없이 외부 음성 서비스를 사용하므로 서비스 상태에 따라 일시적인 지연이 생길 수 있습니다.
- 저작권 점검은 위험을 줄이기 위한 기능이며 법적 무침해를 보증하지 않습니다.
