# 쇼츠메이커 WEB V2.2 적용 방법

## GitHub에 교체/추가할 항목
- streamlit_app.py
- shorts_engine.py
- requirements.txt
- packages.txt
- assets 폴더 전체
- .streamlit 폴더

기존 저장소에서 Add file → Upload files로 위 항목을 올린 뒤 Commit changes를 누르세요.
Streamlit이 자동 재배포하지 않으면 앱 우측 메뉴 → Reboot app을 누르세요.

## V2.2 핵심 변경
- 영상의 노란색 콘텐츠 유형 라벨 완전 제거
- 기사 사진과 방송 캡처 자동 사용 제거
- Pexels 스톡 또는 자체 생성 그래픽만 사용
- 기사 사실 기반 독창 대본 강화
- AI 성우 또는 내 목소리 녹음/업로드 선택
- 내 목소리 4종 보정: 깔끔 / 밝게 / 재밌게 / 따뜻하게
- 콘텐츠 유형에 맞춘 오리지널 BGM 자동 선택
- YouTube 오디오 라이브러리 음원 직접 업로드 지원
- 저작권 점검, 시각자료 출처, 음악 라이선스, AI 공개 안내 파일 생성

## 내 목소리 사용 주의
짧은 음성 샘플만으로 새로운 대본을 자동으로 읽게 만드는 음성복제 기능은 포함하지 않았습니다.
대본을 직접 읽어 녹음하면 프로그램이 노이즈 제거, EQ, 압축, 음량 정리, 가벼운 음색·속도 보정을 적용합니다.
